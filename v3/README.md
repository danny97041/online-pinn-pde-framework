# 온라인 PINN PDE 프레임워크 V3

해석해가 있는 PDE의 저장 실험 비교, 모델 추론, 검색, 자연어 도구 호출 및 선택적 추가 학습을 제공합니다.
통합 결과 ZIP에는 9개 방정식·65개 완료 실험이 포함되어 있습니다.

[Colab에서 열기](https://colab.research.google.com/github/danny97041/online-pinn-pde-framework/blob/main/outputs/Online_PINN_PDE_Framework_V3.ipynb) · [배포 파일](https://github.com/danny97041/online-pinn-pde-framework/releases) · [Colab 사용법](COLAB.md)

## 비교 대상

| 방정식 | 저장 시드 수 | 문제 방향 |
| --- | ---: | --- |
| 2차원 파동 | 3 | 역문제 |
| 2차원 열전도 | 3 | 순방향 |
| 2차원 포아송·버거스·2차원 Darcy·반응–확산 | 각각 1 | 순방향 |
| Navier–Stokes · Kovasznay | 각각 1 | 순방향·역문제 |
| Navier–Stokes · Taylor–Green | 1 | 순방향 |

각 문제는 기본 PINN, 손실항 SA, 푸리에 특징, 푸리에 특징 + 손실항 SA, 푸리에 특징 + 커리큘럼의 5개 방법으로 비교합니다.
물리장 오차와 역문제 계수 오차는 별도 지표입니다. 순방향 문제에는 학습 계수 오차를 부여하지 않습니다.

## 자연어와 검색

Qwen 모델은 `Qwen/Qwen3.5-0.8B`입니다. 요청 의도를 제안하고 제어기가 허용된 도구를 호출합니다.
답변 수치는 저장 결과·계산·모델 예측 도구에서 가져옵니다. Qwen의 의도 판단과 제어기 보정은 별도로 기록합니다.
자연어 질문으로 학습, 셸 실행, 비밀 조회, 파일 삭제를 실행하지 않습니다.

검색은 `multilingual-e5-small`의 정규화 임베딩과 BM25를 가중 RRF로 결합합니다.
E5·BM25 가중치는 0.6·0.4, RRF 상수는 60입니다. 문서 분산과 방정식별 근거 범위를 적용합니다.
E5를 끄면 BM25 경량 검색을 사용합니다. 근거 내용이 바뀌면 캐시를 갱신합니다.

임베딩 검색의 기본 엔진은 NumPy입니다. FAISS를 선택하면 `IndexFlatIP`를 사용합니다.
미설치 또는 로드 실패 시 패널에 **FAISS 설치** 버튼이 표시됩니다. 버튼을 눌렀을 때만 `faiss-cpu`를 설치합니다.
두 엔진은 같은 정규화 임베딩·검색 범위·순위 결합을 사용하며 근사 검색은 적용하지 않습니다.

## 학습 조건과 재개

- 기본 새 학습은 시드 3234 하나입니다. 선택형 4시드는 3234~3237을 순차 실행합니다.
- 5개 방법 모두 실행과 4시드를 함께 선택하면 20개 실험입니다. 설정 확인 화면에 실행 범위를 표시합니다.
- PDE·데이터·경계/초기조건 손실 그룹은 정규화된 1:1:1 비중을 사용합니다. 커리큘럼은 예외로 PDE 비중 0에서 시작하여 10,000회까지 1/3로 늘립니다. SA는 해당 방법에서만 그룹 가중치를 조절합니다.
- 합성 학습점은 기본 5,000 Adam 업데이트마다 LHS로 갱신하며 검증·평가점은 고정합니다.
- 기본 추가 학습 목표는 고정 검증 물리장 상대 L2 10%입니다. Wave의 과거 5% 중단 이력은 그대로 보존합니다.
- Adam과 L-BFGS 종료 지표를 구분합니다. 선택 후처리 모델을 Adam 체크포인트로 취급하지 않습니다.
- `cap`은 재개 전 업데이트를 포함한 누적 Adam 상한입니다.
- 재개는 구조·표본·샘플링 주기·학습률 일정·Adam·SA 상태를 상속합니다. 지원하지 않는 설정 변경은 거절합니다.
- 준비와 개별 실험 완료 경계에서 실행당 ZIP 하나를 갱신합니다. 세션이 종료되면 현재 미완료 실험은 소실될 수 있습니다.

학습 실행 허용을 끈 상태에서는 설정만 확인합니다. 입력·방법·설정을 변경하면 실행 허용을 다시 확인해야 합니다.
입력 ZIP과 완료 모델은 덮어쓰지 않습니다. 4시드 결과를 재개할 때에는 이어 실행할 시드·방법을 각각 선택합니다.

## 문서·시각화·모델 관리

문서 생성은 저장 수치에서 `generated_documents/technical_report.md`와 `feature_catalog.md`를 만들고 검색 근거를 갱신합니다.
Qwen이나 재학습은 필요하지 않습니다.

비교·시드 분산·히트맵은 저장 지표를 사용합니다. 해석해·예측·오차 지도는 선택 모델을 새 격자에서 추론합니다.
시간 의존 문제는 시간 위치, 다성분 모델은 출력 성분을 선택할 수 있습니다. 그림은 PNG·PDF로 저장합니다.
새 시각화 격자의 오차는 저장 참조 격자의 오차와 구분합니다.

기본 추론 모델 지정은 `/predict/active`가 사용할 방법·시드를 선택합니다.
체크섬·모델 로드 확인과 변경 승인 후 적용하며 직전 선택으로 복원할 수 있습니다.
일반 좌표 예측의 명시적 방법·시드 선택과 학습 모델은 바뀌지 않습니다.
선택 이력을 유지하려면 생성된 `V3_Registry.zip`을 다음 입력으로 사용합니다.

## API

| 경로 | 용도 |
| --- | --- |
| `GET /health`, `GET /comparison`, `GET /report` | 상태·비교·요약 |
| `GET /models`, `GET /model/info` | 저장 모델·변수·입력 영역 조회 |
| `POST /predict`, `POST /predict/batch` | 모델을 지정한 좌표 예측 |
| `POST /rag/search`, `POST /rag/context` | 검색 결과·LLM 문맥 |
| `POST /agent/tool`, `POST /agent/ask` | 도구 호출·자연어 질문 |
| `GET /registry`, `POST /predict/active` | 기본 추론 모델 조회·사용 |
| `POST /registry/activate`, `POST /registry/rollback` | 승인된 모델 지정·복원 |

등록 쓰기 API는 `us_app(..., registry_write=True)`로 켠 경우에만 동작합니다.
외부 서버로 제공할 때에는 인증과 접근 제어를 별도로 구성해야 합니다.

## 검사와 결과 해석

검사 범위·실행 방법·기록 위치는 [개발·검증 안내](../docs/DEVELOPMENT.md)에 있습니다.
과거 실행 기록과 현재 소스의 검사 결과는 구분합니다.

저장 실험의 지표 비교입니다. Adam과 선택 후처리는 계산량이 다를 수 있으며, PDE 잔차 원값은 방정식 간 직접 비교하지 않습니다.
물리장 L2 목표와 경계·초기조건·국소 최악점 검사는 별개입니다.
