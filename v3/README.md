# 온라인 PINN PDE 프레임워크 V3

해석해가 있는 PDE 실험을 저장 모델 예측, 하이브리드 검색, 자연어 도구 호출,
선택적 추가 학습으로 연결하는 프레임워크입니다.
통합 결과에는 9개 방정식·65개 완료 실험의 모델과 비교 결과가 포함되어 있습니다.

## 기능

| ACTION | 목적 | 필요한 환경 |
| --- | --- | --- |
| `results` | 저장 비교표와 보고서 | NumPy |
| `predict` | 지정 좌표의 저장 모델 예측 | TensorFlow |
| `agent` | 결과 도구를 이용한 자연어 응답 | FastAPI, 선택적으로 Qwen·E5 |
| `evaluate` | 기본 30문항·추가 표현 15문항과 API 검사 | FastAPI·HTTPX, 예측용 TensorFlow, 선택적으로 Qwen·E5 |
| `train` | 새 학습 또는 Adam 체크포인트 재개 | TensorFlow·SciPy |
| `documents` | 기술보고서·기능 목록 생성 및 검색 편입 | NumPy |
| `visualize` | 비교·시드 분산·히트맵·예측/오차 지도·학습 이력 | Matplotlib, 지도에는 TensorFlow |
| `registry` | 저장 모델 정보·수동 추론 모델 선택·되돌리기 | 선택 변경 시 TensorFlow |

코드 정의는 분리된 셀로 제공되며 기본적으로 접혀 있습니다.
상단 최초 설정은 기능·파일 위치만 받습니다. 60초 무입력 시 저장 결과 조회로 진행하며 선택 변경 시 대기 시간을 다시 계산합니다.
확정하지 않은 학습·검사 선택은 시간 종료 시 조회 기본값으로 되돌립니다. 자동 위치에서 연결된 Drive와 로컬 ZIP이 모두 없으면 Drive 연결을 한 번 요청하며 모델 다운로드는 자동 시작하지 않습니다.
맨 아래 실행 패널에서 한국어 드롭다운 설정과 결과를 한 화면으로 표시합니다.
정의 셀을 초기화한 뒤 기능 변경은 ‘선택한 기능 실행’ 버튼으로 처리합니다.
Drive 인증 실패 시에도 패널이 유지되며 Drive 재연결 또는 로컬 ZIP 사용을 지원합니다.
API 키·방정식 및 방법 식별자는 호환성을 위해 영문으로 유지합니다.
Colab 제공 TensorFlow를 우선 사용하며 특정 버전 일치를 강제하지 않습니다.
도구 검사에는 `fastapi httpx`, 실제 언어 모델·E5 검색에는 `torch transformers>=5`가 필요합니다.
선택 기능의 의존성만 필요합니다. 모델은 해당 기능을 처음 사용할 때 내려받습니다.

## 자연어 도구 호출과 검색

언어 모델은 `Qwen/Qwen3.5-0.8B`입니다. Qwen은 요청 의도를 제안하고,
제어기는 허용된 도구만 호출합니다. 숫자는 저장 결과와 계산 도구에서 가져옵니다.
Qwen의 판단 일치와 제어기의 보정 횟수를 별도로 기록하며
시스템의 성공을 언어 모델 단독 정확도로 표시하지 않습니다.
셸 실행·비밀 조회·파일 삭제·자동 재학습은 허용하지 않습니다.

다국어 E5와 BM25의 가중치는 0.6과 0.4, 순위 결합의 RRF 상수는 60입니다.
문서별 근거 분산, 질의·문서 접두사, 평균 풀링을 사용합니다.
정규화 임베딩의 내적은 NumPy가 기본입니다. **E5 + BM25 검색**을 켠 뒤
**임베딩 검색 엔진 → FAISS**를 선택하면 `IndexFlatIP`를 사용합니다.
FAISS 선택 경로에만 `faiss-cpu`가 필요하며 설치되지 않았으면 안내 오류를 표시합니다.
근사 검색을 적용하지 않으며 방정식별 근거 범위·문서 분산·RRF 가중치는 두 경로에서 같습니다.
캐시는 근거 내용의 해시로 구분합니다.
`DENSE_RAG=False`는 BM25만 사용하는 경량 경로입니다.
기본 결과 조회에서는 인덱스를 만들거나 언어 모델을 로드하지 않습니다.

‘자연어 질문’은 직접 입력한 요청을 저장 결과·계산·모델 호출에 연결하고 한국어 문장으로 답합니다.
‘기능 검사 → 추가 시험 질문’에 최대 10문항을 추가할 수 있으며 응답·도구 기록을 보존합니다. 의미 정확도는 직접 확인합니다.

## 추가 학습과 설정 변경

하단 실행 패널에서 ‘추가 학습’, 방정식, 방법, 새 학습 또는 재개를 선택합니다.
‘학습 실행 허용’을 끈 상태에서는 전체 설정만 보여주고 학습하지 않습니다.
‘상세 학습 설정’에서 값을 변경하고 적용 설정 확인 후 학습 실행을 허용합니다.

예: 방법=푸리에 특징, 총 상한=100000, 기준 학습률=0.002, 목표 L2=0.10.
`cap`은 재개 전의 완료 횟수를 포함한 누적 Adam 상한입니다.
새 실험의 기본 시드는 3234 하나입니다.
**시드 실행 범위 → 4시드**를 선택하면 3234·3235·3236·3237을 순차 실행합니다.
**5개 방법 모두 실행**도 선택할 수 있습니다. 설정 확인에는 총 실험 수가 표시되며
4시드와 5개 방법을 함께 선택하면 20개 실험입니다. 계산량은 기본 1시드·1방법보다 증가합니다.
시드별 완료 실험은 하나의 누적 ZIP에 저장하며 평균·표본 표준편차·10% 도달 수를 집계합니다.
4시드 ZIP에서 재개할 때는 완료된 시드와 방법을 각각 선택합니다.

과거 Adam 체크포인트는 ‘선택한 통합 결과에서 재개’를 선택합니다.
추가 학습 결과의 재개 ZIP은 목록에서 선택합니다.
구조·샘플링·시드·학습률 일정이 바뀌면 새 학습이 필요하다는 오류를 표시합니다.
Adam·SA·샘플링 주기를 복원하며 L-BFGS 선택 모델을 Adam 상태로 가장하지 않습니다.
Wave의 저장 구조·정규화·표본 수·SA 구현을 보존하고 지원하지 않는 변경은 명시적으로 거부합니다.

준비와 개별 실험 완료 경계에서 실행당 하나의 ZIP을 갱신합니다.
partial ZIP은 만들지 않습니다. 연결이 끊기면 진행 중이던 미완료 실험은 유실될 수 있습니다.
입력 통합 결과는 변경하지 않습니다.

## 문서·시각화·모델 등록

**보고서·기능 목록 생성**은 저장된 수치로 `generated_documents/technical_report.md`와
`generated_documents/feature_catalog.md`를 생성합니다. Qwen이나 재학습은 사용하지 않습니다.
문서는 검색 근거에 편입하며 Agent의 `generate_report`, `generate_feature_catalog`도 재색인을 수행합니다.

**결과 시각화**에서 비교표·시드 분산·방정식 히트맵은 저장 수치를 사용합니다.
해석해·예측·오차 지도는 선택 체크포인트를 새 8~64 격자에서 추론합니다.
시간이 있는 방정식은 시간 위치, 다성분 모델은 출력 성분을 선택합니다.
새 시각화 격자의 수치를 저장 참조 오차로 바꾸어 기록하지 않습니다. PNG·PDF를 함께 저장합니다.

**추론 모델 관리**는 모델 정보 조회가 기본입니다. 선택 변경을 승인하면 체크섬과 모델 로드를 확인한 뒤
해당 방정식의 추론 모델을 지정하고 이전 선택으로 되돌릴 수 있습니다.
이는 `/predict/active`의 모델 선택이며, 일반 `/predict`는 전달한 방법·시드로 예측합니다.
학습 파일과 입력 ZIP은 수정하지 않습니다. 변경 상태는 출력 `V3_Registry.zip`에 포함됩니다.

API는 요청 스키마 → 라우터 → 서비스 → 모델/등록 모듈로 분리합니다.
`/models`, `/model/info`, `/rag/context`, `/predict/batch`, `/predict/active`, `/registry`를 제공합니다.
등록 쓰기 API는 `us_app(..., registry_write=True)`로 명시적으로 켠 경우만 동작합니다.
인터넷에 서버를 공개할 때에는 인증·접근 제어를 별도로 구성해야 합니다.

## 검사 기능

자연어·API·65개 모델·재개·LHS 경계 검사가 통과했습니다.
검사 결과와 실행 당시 소스의 해시는 `V3_Results.zip`에 포함되어 있습니다. [검사 범위와 검증 절차](../docs/V3_RELEASE_CHECKLIST.md)에서 세부 내용을 확인할 수 있습니다.

`evaluate`는 쉬움·중간·어려움 각 10문항과 별도 표현 각 5문항을 검사합니다.
도구 순서·수치·근거·응답 상태·위험 요청의 거부를 확인합니다.
API 검사는 내부 요청과 응답을 확인합니다. 외부 서버 배포는 별도 작업입니다.
‘저장 모델 전수 검사’는 모든 선택 모델의 예측과 저장 참조 L2를 재계산합니다.
‘재개·LHS 경계 검사’는 두 방정식의 시험용 Adam 6회와 별도 연결 검사,
Wave Adam의 동일 다음 업데이트 두 복사본 비교, 실제 5000/5001 샘플러 제어를 검사합니다.
전체 5001회 재학습이나 실제 Colab 세션 강제 종료 시험은 아닙니다.

검사 이력은 결과 ZIP의 `validation/`에 있습니다.
새 검사는 `validation/runs/`에 추가하며 `validation/current.json`으로 찾습니다.
과거 검사와 새 실행 검사를 구분하며 실패·미실행을 통과로 처리하지 않습니다.
서비스 확장의 로컬 검사는 `validation/service_local.json`에 별도로 기록합니다.
FAISS 순위 동등성 시험에는 시험용 임베딩을 사용하므로 실제 E5 검색 품질 검사를 대신하지 않습니다.

## 결과 해석의 한계

- Wave와 Heat는 각각 3개 시드, 나머지 7개 방정식은 각각 1개 시드입니다.
- Wave의 과거 5% 중단을 새 10% 목표 실험으로 바꾸어 표시하지 않습니다.
- Adam과 선택 후처리 결과를 분리하며 동일 비용의 우월성을 추론하지 않습니다.
- 방정식 사이에서 단위가 다른 PDE 잔차 원값을 직접 순위화하지 않습니다.
- 순방향 문제의 학습 계수 점수는 해당 없음이며 자동 만점이 아닙니다.
- V3의 10%는 연구 목표입니다. 경계·초기조건 및 국소 최악점의 합격 판정은 별도 검증 대상입니다.
- TensorFlow 버전이 달라도 동일한 학습 경로가 재현된다고 주장하지 않습니다.

V4 범위: Supervised-only 비교, 실행 출력 포함 데모, L1·L2 동시 5% 목표.
V3의 기본 L2 10% 목표와 과거 저장 결과는 유지합니다.
Navier–Stokes는 Kovasznay·Taylor–Green 문제로 포함되어 있습니다.
전체 방정식 계열의 역문제·원통 후류와 추가 수송·음향·탄성 문제 계획은 `docs/V4_RESEARCH_PLAN.md`에 정리합니다.
