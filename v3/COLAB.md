# 온라인 PINN PDE 프레임워크 V3

## 빠른 시작

`Online_PINN_PDE_Framework_V3.ipynb`와 `V3_Results.zip`을 `MyDrive/PINN`에 함께 두고 **모두 실행**하세요.
저장 비교표가 결과 탭에 표시됩니다. 결과 조회에는 재학습·GPU·TensorFlow·Qwen이 필요하지 않습니다.
코드 정의 셀은 기본적으로 접혀 있으며, 설정·결과 패널은 노트북 하단에 있습니다.
원본 코드는 각 셀의 코드 표시로 열어볼 수 있습니다.

## 설정 탭

| 기능 | 표시되는 항목 | 학습 여부 |
| --- | --- | --- |
| 저장 결과 보기 | 통합 ZIP | 없음 |
| 좌표 예측 | ZIP·방정식·방법·시드·좌표 | 없음 |
| 자연어 질문 | ZIP·질문·Qwen·검색 방식 | 없음 |
| 기능 검사 | ZIP·Qwen·검색 방식·선택 검사 | 시험용 학습 검사를 선택했을 때만 |
| 추가 학습 | ZIP·방정식·방법·시드·새 학습/재개·설정 | 학습 실행 허용을 켠 경우만 |

기능을 바꾸면 관련된 설정만 활성화됩니다. 숨겨진 옵션은 실행 요청에서도 제외합니다.
손실항 SA 설정은 SA 비교군에서만, FF 설정은 FF 비교군에서만 표시합니다.
Wave의 보존된 구조·표본·SA 설정은 변경 항목으로 표시하지 않습니다.
재개 시 구조·샘플링·학습률 일정은 부모 ZIP에서 상속하며, 누적 상한과 중단·후처리 설정만 바꿀 수 있습니다.

추가 학습은 먼저 **학습 실행 허용을 끈 채 실행**하여 전체 설정을 확인하세요.
방정식을 선택하고 펼침 설정에서 수치와 LR 비율 등을 수정할 수 있습니다.
`0.10`은 10%, 상한은 완료 횟수를 포함한 누적 Adam 횟수입니다.
기본 시드는 3234 하나입니다. 학습점은 기본 5천 회마다 LHS로 교체하고 검증·평가점은 고정합니다.

ZIP은 파일 목록에서 선택합니다. 긴 파일명의 과거 통합 결과·검사 ZIP도 내용이 맞으면 사용 가능합니다.
실행하면 **결과 · 실행 로그** 탭으로 자동 이동합니다. 설정 탭의 이동 버튼도 사용할 수 있습니다.

## 검사와 출력 파일

기능 검사는 쉬움·중간·어려움 각 10문항, 별도 표현 15문항, 도구·API를 확인합니다.
Qwen 사용을 켜면 실제 모델을 사용하며 시스템 통과와 Qwen 판단 일치는 따로 기록합니다.
E5 + BM25를 끄면 가벼운 BM25 검색을 사용합니다.

- **저장 모델 전수 검사**: 입력 ZIP의 모든 선택 모델 예측·반복·단일/배치 일치와 저장 참조 L2 재계산.
- **재개·LHS 경계 검사**: 두 방정식 새 학습/재개 6회와 별도 연결 검사, Wave Adam 다음 업데이트 두 복사본 비교, 5000/5001 샘플러 교체 제어 검사.
- LHS 경계 검사는 실제 샘플러를 사용하지만 전체 5001회 학습을 반복하는 성능 실험은 아닙니다.
- 실제 Colab 세션 강제 종료나 장시간 학습 경로 전체를 인증하는 검사는 아닙니다.

검사 결과는 `V3_Check.zip`, 추가 학습은 `V3_Train_<방정식>_<8자리 실행번호>.zip`입니다.
입력 ZIP과 이전 검사 ZIP은 덮어쓰지 않습니다. `V3_Check.zip`이 이미 있으면 새 검사 출력에는 실행번호를 붙입니다.
검사 이력은 `validation/runs/`, 최근 검사 위치는 `validation/current.json`에 기록됩니다.
이전 Qwen·API 검사와 그때의 소스는 보존하며 수정본의 통과로 간주하지 않습니다.
partial ZIP은 만들지 않습니다. 학습 준비·실험 완료 경계의 ZIP만 갱신하므로 세션 종료 시 미완료 실험은 소실될 수 있습니다.

## 실행 환경과 해석 범위

설정 패널은 ipywidgets, 결과 조회는 NumPy를 사용합니다. Colab에 기본 설치된 패키지를 우선 사용합니다.
예측·학습은 TensorFlow, 도구·API 검사는 `fastapi httpx`, Qwen·E5는 `torch transformers>=5`가 필요합니다.
선택 기능의 패키지가 없으면 해당 기능에만 설치가 필요합니다. TensorFlow 버전은 강제하지 않습니다.
T4 또는 L4를 유지해도 되며 셀별 장치 전환은 필요하지 않습니다.

V3 10%는 연구용 물리장 목표이지 산업 인증 기준이 아닙니다. Wave의 과거 5% 중단 이력은 보존합니다.
방정식 사이의 잔차 원값은 직접 비교하지 않으며 경계·초기조건·국소 최악점 판정은 별도 검증 대상입니다.
