# Colab 사용법

## 준비와 실행

1. `Online_PINN_PDE_Framework_V3.ipynb`와 `V3_Results.zip`을 `MyDrive/PINN`에 둡니다.
2. Colab에서 노트북을 열고 **런타임 → 모두 실행**을 선택합니다.
3. **최초 설정**에서 기능·파일 위치를 선택하고 **선택 적용**을 누릅니다. 60초 동안 입력이 없으면 저장 결과 조회로 진행합니다.
4. 맨 아래 실행 패널에서 필요한 설정을 선택하고 **선택한 기능 실행**을 누릅니다. 결과는 패널 아래에 표시됩니다.

코드 정의 셀은 기본적으로 접혀 있습니다. 코드 표시를 펼치면 원문을 확인할 수 있습니다.
기능 변경 시 해당 설정만 표시하며, 기본 조회에서 재학습·Qwen 다운로드·선택 검사를 시작하지 않습니다.
최초 설정의 시간 표시가 멈추면 **기본 조회로 바로 진행** 또는 **선택 적용**을 사용할 수 있습니다.

## 파일 위치

기본 저장 폴더는 `/content/drive/MyDrive/PINN`입니다.
자동 위치는 연결된 Drive, 로컬 ZIP 순으로 확인합니다. 둘 다 없으면 Drive 연결 인증을 요청합니다.
인증 실패 후에는 **Drive 연결**로 다시 연결하거나 **로컬 ZIP 사용**을 선택합니다.

로컬 사용은 Colab 왼쪽 파일 패널에 `V3_Results.zip`을 업로드한 뒤 선택합니다.
로컬 파일은 런타임 삭제 시 소실되므로 출력 ZIP은 종료 전에 다운로드해야 합니다.
파일을 추가하거나 폴더를 바꾸면 **ZIP 목록 새로고침**을 누릅니다.

## 기능별 설정

| 기능 | 설정 |
| --- | --- |
| 저장 결과 보기 | 통합 결과 ZIP |
| 좌표 예측 | 방정식·방법·시드·영역 내 좌표 JSON |
| 자연어 질문 | 직접 질문, Qwen·E5 사용 여부, 검색 엔진 |
| 기능 검사 | Qwen·E5, 저장 모델 전수 검사, 재개·LHS 검사, 추가 질문 |
| 추가 학습 | 방정식·방법·시드·시작 방식·상세 학습 설정·학습 실행 허용 |
| 보고서·기능 목록 생성 | 통합 결과 ZIP |
| 결과 시각화 | 그림 종류·방정식·방법·시드, 필요 시 시간·출력 성분 |
| 추론 모델 관리 | 모델 정보 조회·기본 모델 지정·직전 선택 복원 |

FAISS를 선택했는데 사용 가능하지 않으면 **FAISS 설치** 버튼을 누릅니다.
설치 후 같은 질문이나 검사를 다시 실행합니다. NumPy 검색에는 설치가 필요하지 않습니다.

## 추가 학습과 재개

1. **추가 학습**에서 방정식·방법·시작 방식을 선택합니다.
2. **상세 학습 설정**을 펼쳐 값을 확인·변경합니다. 학습 허용이 꺼져 있으면 설정만 출력합니다.
3. 적용할 설정을 확인한 뒤 **학습 실행 허용**을 켜고 실행합니다.

재개는 저장된 구조·샘플링·학습률 일정을 사용합니다. 설정 변경이 필요하면 새 학습을 선택합니다.
Wave의 보존된 모델 구조와 정규화는 변경하지 않습니다.
기본 1시드이며 선택형 4시드·5방법 일괄 실행이 가능합니다.
`cap`은 누적 Adam 상한, 목표 L2 `0.10`은 10%입니다.

준비·개별 실험 완료 경계에서 ZIP을 저장합니다. 진행 중인 미완료 실험은 세션 종료 시 소실될 수 있습니다.
입력 ZIP과 완료 결과는 변경하지 않습니다.

## 출력 파일

| 기능 | 파일명 |
| --- | --- |
| 기능 검사 | `V3_Check.zip` |
| 추가 학습 | `V3_Train_<방정식>_<실행번호>.zip` |
| 문서 생성 | `V3_Documents.zip` |
| 시각화 | `V3_Plots.zip` |
| 추론 모델 지정·복원 | `V3_Registry.zip` |

같은 이름이 있으면 식별자를 추가합니다. 검사 기록은 출력 ZIP의 `validation/runs/`와 `validation/current.json`에 있습니다.
기능 검사에는 자연어 30문항과 별도 표현 15문항이 포함됩니다. 추가 시험 질문은 한 줄에 한 문항, 최대 10개이며 의미 정확도는 수동 확인합니다.

## 공유

일반 공유는 뷰어 권한과 사본 저장을 사용합니다. 편집자는 원본 셀을 수정·삭제할 수 있습니다.
다른 사용자는 자기 사본과 런타임에서 실행하며 소유자의 런타임·Drive 접근 권한은 공유되지 않습니다.
