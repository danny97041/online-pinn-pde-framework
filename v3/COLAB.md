# 온라인 PINN PDE 프레임워크 V3

물리정보 신경망(PINN)의 실험 결과, 저장 모델 추론, 자연어 도구 호출 및 추가 학습을 제공하는 실행 노트북입니다.
통합 결과 묶음은 9개 방정식의 65개 완료 실험을 포함합니다.

## 실행 절차

1. `Online_PINN_PDE_Framework_V3.ipynb`와 `V3_Results.zip`을 `MyDrive/PINN`에 배치합니다.
2. **런타임 → 모두 실행**으로 분리된 정의 셀을 초기화합니다. 정의 셀의 코드는 기본적으로 접혀 있습니다.
3. 상단 **최초 설정**에서 기능과 파일 위치만 선택하고 **선택 적용**을 누릅니다. 60초 동안 입력이 없으면 **저장 결과 보기 · 자동 위치**로 진행합니다. 선택을 변경하면 대기 시간이 다시 시작됩니다.
4. 맨 아래 **실행 패널**에서 선택 기능에 필요한 ZIP·방정식·방법·세부 설정만 조절합니다. 기능을 바꾸면 표시 항목도 바뀝니다.
5. **선택한 기능 실행** 버튼으로 요청을 실행합니다. 결과는 설정 바로 아래에 표시됩니다. 저장 결과 조회는 선택 ZIP이 확인되면 자동 표시됩니다.

기본 동작은 저장 결과 조회입니다. 전체 실험의 재학습, 언어 모델 다운로드 및 선택 검사는 자동으로 시작되지 않습니다.
확정하지 않은 검사·학습 선택도 무입력 종료 시 안전한 조회 기본값으로 되돌립니다. Colab 타이머는 브라우저에서 커널에 시간을 확인하므로 노트북 탭과 런타임이 연결되어 있어야 합니다. 셀을 60초 동안 붙잡지 않습니다.
남은 초가 멈추거나 자동 연결이 종료되면 맨 아래 **기본 조회로 바로 진행**을 누릅니다. 학습·검사는 시작하지 않으며, 자동 파일 위치에 따라 필요한 경우 Drive 연결 인증을 요청합니다.
코드 원문은 각 정의 셀의 코드 표시에서 확인할 수 있습니다.

## 제공 기능

| 기능 | 처리 내용 | 학습 실행 |
| --- | --- | --- |
| 저장 결과 보기 | 방정식·방법별 비교표와 보고서 | 없음 |
| 좌표 예측 | 지정 좌표의 저장 모델 추론 | 없음 |
| 자연어 질문 | Qwen 또는 규칙 기반 도구 호출, 검색 근거 | 없음 |
| 기능 검사 | 자연어·API 검사와 선택적 모델·재개 검사 | 시험 검사를 선택한 경우만 |
| 추가 학습 | 선택 방정식·방법의 새 학습 또는 Adam 재개 | 학습 실행 허용을 켠 경우만 |

설정 패널에는 선택 기능에 해당하는 항목만 표시됩니다.
자연어 질문의 **직접 입력할 질문**에 자유롭게 작성할 수 있습니다. 답변은 도구로 확인한 수치를 한국어 문장으로 정리하며 모르는 사실을 생성하지 않습니다.
기능 검사의 **추가 시험 질문**은 한 줄에 한 문항, 최대 10문항입니다. 답변과 도구 호출을 저장하며 의미 정확도는 직접 확인합니다.
손실항 SA와 FF 설정은 해당 비교군에서만 적용됩니다. 상세 학습 설정은 접힌 영역에서 관리합니다.
학습 허용을 끈 추가 학습 요청은 실제 적용 설정만 출력합니다. 기능·방정식·방법·입력 변경 시 허용은 자동 해제됩니다.
재개 시 구조·표본·학습률 일정은 저장 상태를 상속합니다. Wave의 보존된 구조와 정규화는 변경하지 않습니다.
기본 LHS 교체 주기는 5천 Adam 업데이트이며 검증·평가점은 고정됩니다. 목표 L2 입력값 `0.10`은 10%입니다.

## 저장소

기본 위치는 `/content/drive/MyDrive/PINN`입니다.
이미 연결된 Drive에는 재인증을 요청하지 않습니다. 연결 여부와 PINN 하위 폴더 존재 여부는 별도로 확인합니다.
자동 위치는 연결된 Drive를 우선 사용하고, Drive가 미연결이면 로컬 ZIP을 확인합니다. 둘 다 없으면 패널을 먼저 표시한 뒤 Drive 연결을 한 번 시도합니다. 인증은 사용자가 승인해야 합니다.
인증 취소·실패 후에는 자동으로 재시도하지 않으며 하단에서 수동 재연결 또는 로컬 업로드를 선택합니다. ‘로컬’ 선택에서는 Drive 연결을 시도하지 않습니다.
미연결 Drive를 사용할 때는 상단에서 **Google Drive · 연결 요청**을 명시적으로 적용하거나 하단 **Drive 연결**을 누릅니다.
인증 실패는 연결 성공으로 처리하지 않으며 실행 패널은 계속 표시됩니다.
**저장소 · 파일 위치**에서 **Drive 연결**로 재연결하거나 **로컬 ZIP 사용**으로 전환할 수 있습니다.

로컬 경로는 `/content`입니다. Colab 왼쪽 파일 패널에서 `V3_Results.zip` 업로드 후 **로컬 ZIP 사용**을 선택합니다.
로컬 입력과 출력은 런타임 삭제 시 유실될 수 있으므로 생성된 ZIP의 별도 다운로드가 필요합니다.
파일 추가나 폴더 변경 후 **ZIP 목록 새로고침**으로 목록을 갱신합니다.

## 출력과 검사 이력

- 기능 검사: `V3_Check.zip`. 같은 이름이 존재하면 식별자가 추가됩니다.
- 추가 학습: `V3_Train_<방정식>_<실행번호>.zip`.
- 입력 ZIP과 이전 검사 ZIP은 덮어쓰지 않습니다.
- 검사 기록: ZIP의 `validation/runs/`. 최근 검사 위치: `validation/current.json`.
- 학습은 준비·완료 경계에서 저장되며 partial ZIP은 생성하지 않습니다. 진행 중인 미완료 실험은 복구가 보장되지 않습니다.

자연어 검사는 쉬움·중간·어려움 각 10문항과 별도 표현 15문항을 포함합니다.
Colab에서는 브라우저 콜백으로 시간을 확인합니다. 다른 노트북에서는 실행 중인 asyncio 루프 또는 커널의 기존 IOLoop을 사용하며, 미지원 환경은 수동 선택으로 진행합니다.
저장 모델 전수 검사와 재개·LHS 경계 검사는 선택 항목입니다.
Qwen의 판단 일치와 시스템 전체 통과는 구분하며 과거 검사 이력은 현재 실행의 통과로 간주하지 않습니다.
LHS 경계 검사는 실제 샘플러의 교체 동작을 확인합니다. 5001회 전체 재학습은 하지 않습니다.

## 실행 환경과 결과 해석

설정은 ipywidgets, 결과 조회는 NumPy, 모델 추론·학습은 TensorFlow를 사용합니다.
API 검사는 `fastapi httpx`, Qwen·E5는 `torch transformers>=5`가 필요합니다.
선택 기능의 의존성만 사용하며 TensorFlow 버전을 강제하지 않습니다. GPU는 추론·학습 또는 언어 모델 실행 시 선택적으로 사용됩니다.

비교표는 저장된 실험 결과입니다. 10%는 이 실험의 물리장 오차 목표입니다.
Wave의 과거 5% 중단 이력은 보존합니다. 방정식 간 단위가 다른 잔차 원값은 직접 순위화하지 않습니다.
경계·초기조건과 국소 최악점의 정밀 판정은 별도 검증 대상입니다.

## 공유

일반 배포는 뷰어 권한으로 공유하고 사본·다운로드를 허용합니다. 편집자는 원본 셀을 수정·삭제할 수 있으며 질문 도구의 제한이나 코드 접기가 이를 막지 않습니다.
공유되는 노트북에는 코드와 저장 출력이 포함되지만 소유자의 런타임은 공유되지 않습니다. 다른 사람이 수정한 코드를 자신의 Drive에 연결해 실행하기 전에는 검토가 필요합니다.
뷰어는 복사가 허용되면 자기 사본과 런타임에서 실행할 수 있습니다. 실제 원본 화면의 실행 가능 여부와 조직별 제한은 별도 계정에서 확인합니다.
