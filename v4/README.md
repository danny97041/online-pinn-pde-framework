# 온라인 PINN PDE 프레임워크 V4

순·역문제 학습 비교, PDE 적응형 샘플링(RAD), 저장 모델 추론, 실제 데이터 연결과 Colab 실행 패널을 제공합니다.
기본 기능은 저장 결과 조회이며 학습은 명시적으로 허용해야 시작합니다.
V3에서 가져온 결과는 `historical/`에 보관하며 V4 완료 실험으로 집계하지 않습니다.

## 배포 파일과 실행

노트북과 사용할 결과 ZIP을 `MyDrive/pinnV4`에 두고 모두 실행합니다.
접힌 정의 셀 아래의 패널에서 기능을 선택하며, 저장 결과 조회에는 GPU나 재학습이 필요하지 않습니다.
실험 수는 선택한 ZIP의 완료 결과를 기준으로 집계합니다. V4 학습은 독립 실행이며 V3 모델을 이어 학습하지 않습니다.
단계별 사용 방법은 [Colab 안내](COLAB.md)에 있습니다.

## 공통 정책

- 최대 Adam 100,000회. 15,000회부터 1,000회마다 고정 검증점의 상대 L1과 L2가 모두 5% 이하인지 확인하며 3회 연속 만족하면 종료합니다.
- 6개 방법: 기본 PINN, 손실항 SA, FF, FF+손실항 SA, FF+커리큘럼, Supervised-only. 기본 1시드, 선택형 4시드.
- PDE 학습점만 5,000회마다 RAD로 선택합니다. 나머지 합성 학습점은 LHS로 갱신합니다. CSV 관측·조건 값은 임의 생성하거나 갱신하지 않습니다.
- FF는 주파수 뱅크별 32개, 척도 0.125/0.25/0.5, MLP 폭 64·깊이 5가 기본입니다.
- 입력을 물리 좌표에서 [-1,1]로 정규화하며 자동미분은 물리 좌표 기준으로 계산합니다. 출력·잔차 척도는 방법과 시드에 공통이며 제외 구역·미래 관측값은 척도 계산에 사용하지 않습니다.
- PDE:관측 데이터:경계·초기조건 그룹은 1:1:1에서 시작합니다. 손실항 SA 방법만 기울기 크기와 지수이동평균(EMA)으로 그룹 가중치를 조절합니다. 점별 SA는 사용하지 않습니다.
- 커리큘럼 방법은 PDE 비중을 0에서 1/3까지 100회 간격으로 균등하게 올려 10,000회에 도달합니다. 첫 100회는 PDE 가중치와 계수 기울기가 0입니다.
- 신경망 학습률은 0.004 → 0.003 → 0.002, 계수 학습률은 0.000004 → 0.003 → 0.004이며 각각 0·5,000·10,000회 기준입니다. 계수는 양수로 매개화하며 Supervised-only는 계수를 추정하지 않습니다.
- Adam 업데이트, L-BFGS 반복과 함수 평가를 별도 기록합니다. L-BFGS 동안 점·SA 가중치를 고정하며, 학습 목적함수와 검증 오차로 선택 여부를 판단합니다. 최종 평가점은 선택에 사용하지 않습니다.
- 20% 한도 지점마다 단일 재개 ZIP을 덮어쓰고 Adam 종료에서도 저장합니다. 완료 결과 ZIP을 검증한 후 해당 재개 슬롯만 제거합니다. 원본 ZIP과 완료 모델은 유지합니다.
- Optuna와 자동 하이퍼파라미터 탐색은 포함하지 않습니다.

최대 반복에 도달하면 목표 미달이어도 실험을 종료하고 달성 여부를 따로 기록합니다.
세부 값은 패널의 **변수별 설명·학습 설정**에서 변경합니다. 새 독립 실험에 적용되며 재개 시에는 저장된 설정을 유지합니다.

| 설정 | 기본값 |
| --- | --- |
| PDE / 합성 관측 / 초기조건 점 수 | 800 / 200 / 160 |
| 공간 경계면당 점 수 | 80 |
| 고정 검증 / 평가점 수 | 256 / 1,024 |
| RAD 후보점 / 잔차 지수 / 균일 혼합값 | 4,000 / 1 / 1 |
| SA 갱신 간격 / EMA / 배율 범위 | 50회 / 0.9 / 0.25~4 |
| L-BFGS 최대 반복 | 500; 0이면 생략 |
| 합성 관측 노이즈 | 0%; 물리장 척도에 대한 Gaussian 표준편차 |

초기조건은 시간 의존 문제에만 적용합니다. CSV 관측·조건 점 수는 연결한 파일의 행 수를 사용합니다.

## 방정식·추정 계수

| 방정식 | 역문제 대상 |
|---|---|
| wave2d | 파동 PDE 계수 lambda1 |
| heat2d | 열확산 계수 alpha |
| poisson2d | 알려진 외력 형태의 진폭 A |
| burgers | 점성 nu |
| kovasznay / taylor_green | 동점성 nu |
| darcy2d | 알려진 공간 투수계수 형태의 배율 |
| reaction_diffusion / advection_diffusion | 확산 D |
| helmholtz | 파수 제곱 |
| elasticity2d | 알려진 Poisson 비 0.25에서 Young 계수 |
| cylinder_ns | 외부 원통 후류 데이터의 동점성 nu |

합성 문제는 알려진 외력과 Dirichlet 조건을 가진 독립 제조해 벤치마크입니다. V3의 특정 조건을 그대로 재현한 실험은 아닙니다.
원통 후류는 직사각형 ROI의 관측·조건·압력 기준·출처가 필요합니다. 원통 장애물 내부가 포함된 비직사각형 영역의 메시 솔버는 제공하지 않습니다.
역문제는 하나의 양수 계수만 추정합니다. 계수 오차와 물리장 오차를 별도로 보고하며 순방향 및 관측값 회귀에는 학습 계수 점수를 부여하지 않습니다.

## 진단·서비스

- 손실 그룹 gradient norm·상충 cosine·계수 gradient·LR·SA·RAD 기록과 상태 보존 검사.
- 정기 진단에서 모델·최적화·난수 상태가 변경되지 않았는지 확인합니다. ZIP은 CRC와 SHA로 검사합니다.
- 고정점의 PDE RMS/p99/max, 경계·초기조건 및 압력 기준 오차, 표면 유속·체적 적분 수지. 지표의 평가점과 적분 규칙을 결과에 기록합니다.
- 보고서·기능 목록 자동 생성과 RAG 재색인, 참조해·예측·오차·잔차 지도 및 학습·진단 그림.
- API 계층: `api_schemas.py` → `api_routes.py` → `services.py` → `runtime.py`. 학습 API는 제공하지 않으며 문서·등록 변경 API는 기본 차단합니다.
- Qwen 도구 라우팅, BM25/E5 RRF, 선택형 FAISS 설치. Qwen 실제 호출과 규칙 답변을 구분합니다. 자연어 답변의 의미 정확도는 별도 평가합니다.
- 동일 ZIP의 질문·검색·예측에서는 모델을 지연 로드 후 재사용하며 ZIP 변경 시 서비스 캐시를 초기화합니다. 화면을 여는 것만으로 모델을 다운로드하지 않습니다.
- 실행 패널의 `선택 기능 확인`은 선택한 Qwen/E5/FAISS와 직접 입력한 질문을 실행하고 호출 기록을 저장합니다.
- 완료 모델 로드·유한 예측·파일 해시 확인 후 수동 기본 추론 모델 지정 및 직전 모델 복원.
- 여러 방정식·순/역문제·노이즈·초기값 조건을 하나의 명시적 계획으로 실행할 수 있습니다. 완료 실험은 건너뜁니다.

API는 완료 결과를 조회·추론하는 인터페이스입니다.

## 16개 공간 구역

- 공간축 2개: x/y 영역을 4×4로 등분. 공간축 1개: 16개 구간으로 등분. 시간은 보간 분할에 포함하지 않습니다.
- 구역 번호는 0~15이며 2D에서는 x 방향이 먼저 증가합니다.
- 기본 제외 번호: `(5 × (seed − 3234) + 7) mod 16`.
- 시드 3234~3237은 각각 7, 12, 1, 6번 구역을 제외합니다. 16개 연속 시드는 모든 구역을 한 번씩 선택합니다.
- 같은 시드의 모든 방법은 같은 구역을 제외합니다. LHS/RAD 교체나 재개 시 구역은 바뀌지 않습니다.
- 구역 경계의 점은 양의 방향 구역에 포함하고, 전체 영역의 최대 좌표는 마지막 구역에 포함합니다.
- 제외 구역의 관측값만 학습·중단 검증에서 제외합니다. 알려진 경계·초기조건·압력 기준점은 유지하고 PDE 점도 유지합니다.
- 원본 관측 파일은 수정하지 않습니다. 남긴 좌표와 관측값의 행 대응을 보존합니다.
- 동일 구역에서 순수 시드 변동을 비교하려면 `block_override`를 지정합니다. 기본 시드별 분할 결과의 분산에는 구역 차이가 포함됩니다.
- 공간 면적은 1/16이지만 실제 관측 제외 비율은 분포에 따라 달라지므로 제외·유지 행 수를 결과에 기록합니다.
- 제외 구역 또는 남은 영역에 관측이 전혀 없으면 실험 준비를 거절합니다.

## 시간 외삽

시작 시간이 0이 아니어도 `t_cut = t_min + 0.8 × (t_max − t_min)`을 사용합니다.
학습·중단 검증은 `t <= t_cut`, 최종 외삽 평가는 `t > t_cut`입니다.
PDE/RAD 후보점, 관측, 시간 의존 경계조건 및 압력 기준점 등 모든 학습 가족에 동일하게 적용합니다.
초기조건은 원래 시작 시점에 유지합니다. 정상 문제에는 시간 외삽을 허용하지 않습니다.
신경망 입력 정규화의 전체 좌표 영역과 실제 학습 샘플링 영역은 구분하여 저장합니다.

## 분할 계약

`GeneralizationPlan`은 제외 구역·시간 범위와 고정 평가점을 정의합니다.
실행기는 모든 학습점 갱신과 재개에서 이 계약을 확인하며, 저장된 분할과 현재 분할이 다르면 재개를 거절합니다.
제외 관측값은 학습·중단·RAD·척도 계산에 사용하지 않습니다. Adam과 L-BFGS는 동일한 고정 평가점에서 별도로 보고합니다.
좌표 해시·관측 행 수·학습 및 평가 범위는 실행 결과에 저장합니다.

벡터 출력은 성분별 오차도 별도로 보고합니다. 참조장이 모두 0이면 상대 오차는 `null`이며 MSE만 계산합니다.
공통 오차 목표는 기본 실험의 L1/L2 동시 5%이며 보간·외삽 성능은 별도 보고합니다.

### 분할 객체 사용 예

from v4 import GeneralizationPlan

plan = GeneralizationPlan(
    domain=((0, 1), (0, 1), (0, 1)),
    spatial_axes=(0, 1),
    time_axis=2,
    mode="interpolation",  # 또는 basic / time_extrapolation
    seed=3234,
)
print(plan.summary())
evaluation_coordinates = plan.fixed_evaluation_points()
