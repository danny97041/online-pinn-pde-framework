# V4 Colab 실행 안내

## 필요한 파일

- `Online_PINN_PDE_Framework_V4.ipynb`
- `V4_Results.zip`

ZIP을 `MyDrive/pinnV4`에 넣거나 Colab 파일 패널의 `/content`에 업로드합니다. 학습 결과를 조회하거나 재개할 때는 `V4_Results_<실행ID>.zip`을 사용합니다.
결과 조회는 GPU가 필요하지 않습니다. 학습은 T4/L4를 권장하며 셀마다 CPU/GPU를 바꾸지 않습니다.
V3의 과거 결과는 `historical/`에 분리되어 있습니다. V4 학습 완료 결과로 계산하지 않습니다.

## 초기 실행 — 재학습 없음

1. 노트북을 열고 모두 실행합니다. 코드는 접힌 정의 셀, 설정 패널, 맨 아래 학습 실행 셀로 구성됩니다. 학습 준비가 없으면 마지막 셀은 즉시 건너뜁니다.
2. Drive 인증이 실패하면 `로컬 ZIP 사용`으로 전환하고 `V4_Results.zip`을 업로드합니다.
3. 저장 폴더와 통합 ZIP을 선택합니다. `저장 결과 보기`에서 해당 ZIP의 완료 실험과 V3 과거 결과를 구분해 확인합니다.

조회만으로 학습·선택 검사·언어 모델 다운로드를 시작하지 않습니다.

## 선택 연결 확인

`선택 기능 확인`에서 확인할 Qwen 또는 E5/FAISS 연결을 선택합니다.
Qwen은 기본 3문항, E5/FAISS는 한 번의 검색 연결을 확인합니다. 직접 입력한 질문이 있으면 기본 질문 대신 해당 질문만 사용합니다.
선택하지 않은 기능은 실행하지 않습니다. 방정식·저장 모델의 개발 검사는 [V4 사용 안내](README.md#소스와-검사)에 정리되어 있습니다.
반환 파일은 `V4_Check_<ID>.zip`이며 실제 호출 여부와 답변을 기록합니다. 의미 정확도 자동 합격으로 표시하지 않습니다.

## 학습 준비와 실행

학습은 패널에서 설정·허용을 선택하고 `학습 설정 확인·실행 준비`를 누른 다음, 맨 아래 `학습 실행` 셀의 ▶를 누릅니다.
버튼 콜백에서는 학습하지 않으며 실제 계산과 로그는 일반 실행 셀에서 이어집니다.
준비 후 설정을 변경하면 다시 준비해야 합니다. 준비는 한 번만 사용할 수 있으며 조회·모두 실행만으로 학습하지 않습니다.
Colab 세션 제한은 별도로 적용되므로 생성된 파일은 Drive에 저장하거나 다운로드합니다.

**본 실험**은 선택 설정으로 학습합니다. **축소 동작 검사**는 10회만 실행하며 성능 비교 결과와 구분합니다.

| 설정 | 입력 |
|---|---|
| 사용할 기능 | 학습 설정·실행 |
| 방정식 | 2차원 파동 |
| 문제 방향 | 역문제 |
| 비교 방법 | 기본 PINN, 손실항 SA, FF, FF+SA, FF+커리큘럼, 관측값 회귀 |
| 시드 구성 | 1시드 |
| 실험 종류 | 기본 비교 |
| 데이터 연결 | 합성 참조 문제 |
| 실행 규모 | 본 실험 또는 축소 동작 검사 |
| 시작 방식 | 새 독립 실험 |
| 학습 실행 허용 | 먼저 끄고 계획 확인 → 실행할 때 켜기 |

`변수별 설명·학습 설정`에서 항목별 설명과 숫자 입력칸을 확인합니다. 목표 오차는 백분율로 입력합니다(5는 5%). FF 척도와 SA 배율은 쉼표로 구분하며 JSON을 직접 작성할 필요가 없습니다. 선택 방법에 적용되지 않는 항목은 비활성화됩니다. 축소 검사에는 실제 적용 설정과 `execution_scope=disposable_smoke`가 기록됩니다.
필요 패키지가 없으면 하단 설치 버튼을 누릅니다. 특정 TensorFlow 버전으로 교체하지 않습니다.
출력은 `V4_Results_<실행ID>.zip` 하나이며, 완료 시 같은 실행의 `V4_Resume_<실행ID>.zip`은 제거됩니다.

## 본 실험

`본 실험`과 새 독립 실험을 선택합니다. 기본은 한 방정식·한 방향·1시드입니다.
상단에서 시작 방식, 학습 목표, 데이터 연결을 먼저 선택합니다. 합성 문제의 기본 비교와 공간 보간에는 방정식 11개가 표시되며 시간 외삽에는 시간축이 있는 6개가 표시됩니다. 목표를 바꾸면 묶음에서 해당 목표를 지원하는 방정식과 그 순서가 유지됩니다. CSV를 연결하면 데이터 계약에 맞는 방정식 하나를 지정합니다.
방법은 체크박스로 다중 선택할 수 있습니다. `여러 방정식·민감도 조건`을 켜면 방정식을 체크박스로 선택하고 순·역문제, 노이즈 비율과 초기 계수 배율을 한 번에 지정할 수 있습니다.
체크한 방정식은 **실행 순서** 목록 끝에 추가됩니다. 목록에서 방정식을 선택하고 **위로** 또는 **아래로** 눌러 먼저 계산할 방정식을 정하세요. 실행 준비 화면의 화살표 순서대로 방정식별 선택 조건과 방법을 처리합니다. 저장 실행을 재개하면 처음 지정한 순서를 복원합니다.
공통 최대 100,000회, L1/L2 동시 5%, 15,000회 이후 3회 연속 정책입니다. 계획에 표시되는 최악 업데이트 수를 확인한 후 학습을 허용합니다.
4시드는 선택형이며 실험별 기록과 평균·표본 표준편차·목표 도달 수를 별도로 저장합니다.
노이즈와 초기 계수 배율마다 독립 학습을 수행하므로 조건 수만큼 실행 범위가 늘어납니다. 합성 관측 노이즈 입력은 백분율이며 5는 물리장 척도의 5% 표준편차를 뜻합니다.

## 세션 종료 후 재개

1. 결과 `V4_Results_<실행ID>.zip`과 남아 있는 `V4_Resume_<같은 실행ID>.zip`을 같은 폴더에 둡니다.
2. 결과 ZIP을 선택하고 **저장 설정·모델 목록 불러오기**를 누릅니다.
   묶음 실험은 ZIP에서 방정식 목록과 문제 방향을 복원합니다. 재개 화면에서 잠긴 선택값과 실행 범위를 확인하세요. 새 실험에서는 단일·묶음 선택에 맞는 문제 방향이 한 곳에 표시됩니다.
3. 시작 방식이 **저장 실행에서 재개**인지 확인합니다. 학습 결과는 자동으로 이 방식을 선택하고, 초기 카탈로그 `V4_Results.zip`은 **새 독립 실험**을 선택합니다.
4. **학습 실행 허용 → 학습 설정 확인·실행 준비 → 맨 아래 학습 실행 셀 ▶** 순서로 진행합니다.

저장 설정을 불러오면 학습 허용과 이전 실행 준비가 해제됩니다.
재개는 저장 설정·분할·코드를 상속합니다. 설정 또는 학습 코드가 다르면 거절합니다. 변경 실험은 새 실행입니다.
완료된 실험은 건너뛰고 미완료 실험만 마지막 재개 지점에서 이어집니다. 기본 저장 간격은 20,000회이므로 첫 저장 이전 또는 저장 사이 업데이트는 세션 종료 시 소실될 수 있습니다.
L-BFGS 도중 종료되면 Adam 종료 상태부터 후처리를 다시 실행합니다. L-BFGS 내부 반복을 중간 복원하지 않습니다.
학습 패널은 Adam 종료·최종 평가, L-BFGS 시작·반복·종료, 재개/결과 ZIP 저장 단계를 표시합니다.
L-BFGS 진행은 계산이 반환되는 시점에 약 15초 간격으로 표시합니다. 한 번의 계산 자체가 오래 걸리면 표시도 늦어질 수 있습니다.
반복 횟수와 손실·기울기 평가 횟수는 서로 다르며, 표시를 위해 추가 손실 계산을 수행하지 않습니다.
다른 실행 ID의 ZIP이나 V3 ZIP을 재개 입력으로 쓰지 않습니다.

## 실제 데이터

CSV와 JSON 계약을 같은 폴더에 배치하고 `CSV + 알려진 조건`을 선택합니다.
`examples/V4_Data_Template.json`을 참고해 좌표/출력 열, 단위 변환, 영역, 척도, 외력, 알려진 경계·초기조건을 지정합니다.
학습 관측·검증·평가 좌표는 겹칠 수 없습니다. 실제 데이터가 없으면 해석값으로 채우지 않습니다.
파동은 초기 변위와 초기 속도 CSV가 모두 필요합니다. Navier–Stokes는 속도 조건과 알려진 압력 gauge가 필요합니다.
원통 후류는 데이터 출처·사용 조건을 기록해야 하며 직사각형 ROI 안의 유동만 지원합니다.
없는 계수 정답은 오차가 `null`이고 없는 최종 평가 관측은 물리장 최종 정확도를 생성하지 않습니다.

## 보간·외삽 및 결과 활용

- 보간·시간 외삽은 새 독립 실험으로 수행합니다. 보간은 시드별 16구역 중 한 관측 구역을 제외하고 시간 외삽은 앞 80%에서만 모든 학습점을 사용합니다. 기존 기본 비교 모델을 재개해 해당 실험으로 표시하지 않습니다.
- 자연어 질문의 Qwen/E5는 선택형 다운로드입니다. FAISS는 미설치일 때 설치 버튼이 표시됩니다. NumPy 검색으로 시작해도 됩니다.
- 모델·시간·출력 성분을 선택해 reference/prediction/error/residual과 진단 그림을 생성합니다. 실제 데이터에 없는 참조장을 만들지 않습니다.
- 모델 지정/복원은 `/predict/active`의 기본 선택만 바꿉니다. 학습 결과와 직접 선택 예측은 바뀌지 않습니다. 변경 승인 후 생성 ZIP을 다음 입력으로 사용합니다.
