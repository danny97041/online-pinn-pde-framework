# V4 기본 비교

[실험별 수치](comparison_5921593e.csv)는 시드 3234에서 열전도, 포아송, 버거스, Kovasznay, Taylor–Green, Darcy, 반응–확산, 이류–확산, Helmholtz, 선형탄성의 순·역문제를 각각 6개 방법으로 학습한 결과입니다. 각 행은 하나의 실험에서 Adam 또는 L-BFGS가 끝난 시점을 나타냅니다.

| 최종 평가점의 상대 L1·L2 동시 5% 이하 | 실험 수 |
|---|---:|
| Adam 종료 | 116/120 |
| L-BFGS 종료 | 119/120 |

L-BFGS 종료 후 기준을 넘은 조합은 열전도 역문제의 FF + 커리큘럼으로, 상대 L1은 36.58%, 상대 L2는 43.66%였습니다. 학습 중단은 별도의 고정 검증점에서 판정합니다.

CSV의 `l1`, `l2`, `coefficient_error`는 비율입니다. 0.05가 5%에 해당합니다. 계수를 추정하지 않는 조건에서는 계수 오차가 비어 있습니다. 원본 파일명은 `V4_Results_5921593e.zip`입니다.

### 순방향 공간 보간

[보간 결과 CSV](comparison_7e12f791.csv)는 파동을 포함한 11개 방정식의 6개 방법(시드 3234)을 비교합니다. 공간 16구역 중 7번 구역의 관측값을 학습에서 제외했습니다. 그 구역의 최종 평가점에서 상대 L1과 L2가 모두 5% 이하였던 실험은 Adam 종료 시 57/66개, L-BFGS 종료 시 60/66개입니다.

### 저장 모델의 시간 외삽

[시간 외삽 결과 CSV](future_to_3_3234.csv)는 시간 범위 [0, 1]에서 학습을 마친 순방향 모델 36개(6개 방정식, 6개 방법, 시드 3234)의 Adam 및 L-BFGS 가중치를 평가한 결과입니다. 원본은 `V4_Results_a4248875.zip`과 `V4_Results_5921593e.zip`입니다. 모델을 재학습하지 않고 기존 고정 평가점에서 저장 지표를 재현한 뒤, 같은 입력 정규화로 1.01부터 3.00까지 200개 시점의 예측을 합성 참조해와 비교했습니다.

공간 격자는 버거스에서 셀 중심 256개, 2차원 문제에서 32×32개입니다. CSV 오차 열은 백분율이며, 다중 출력에서는 성분별 상대 오차의 최댓값을 사용합니다. `future_*`는 전체 평가점을 모아 계산한 값이고, `endpoint_*`는 3.00 한 시점의 값입니다. 0.20 단위 열에서 예측 구간별 차이를 비교할 수 있습니다.

전체 구간에서 상대 L1과 L2가 모두 5% 이하인 모델은 Adam과 L-BFGS 각각 5/36개(버거스 3개, Taylor–Green 2개)였습니다. 3.00 한 시점에서는 두 단계 각각 버거스 3개만 충족했습니다. 버거스의 전이 중심은 `x = 0.5t`를 따라 이동해 2.00에서 공간 영역의 오른쪽 경계에 도달하므로, 이후 구간의 오차는 전이층이 영역 안에 있는 초기 구간과 함께 해석해야 합니다.
