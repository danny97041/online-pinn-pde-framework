# V4 기본 비교

[실험별 수치](comparison_5921593e.csv)는 시드 3234에서 열전도, 포아송, 버거스, Kovasznay, Taylor–Green, Darcy, 반응–확산, 이류–확산, Helmholtz, 선형탄성의 순·역문제를 각각 6개 방법으로 학습한 결과입니다. 각 행은 하나의 실험에서 Adam 또는 L-BFGS가 끝난 시점을 나타냅니다.

| 최종 평가점의 상대 L1·L2 동시 5% 이하 | 실험 수 |
|---|---:|
| Adam 종료 | 116/120 |
| L-BFGS 종료 | 119/120 |

L-BFGS 종료 후 기준을 넘은 조합은 열전도 역문제의 FF + 커리큘럼으로, 상대 L1은 36.58%, 상대 L2는 43.66%였습니다. 학습 중단은 별도의 고정 검증점에서 판정합니다.

CSV의 `l1`, `l2`, `coefficient_error`는 비율입니다. 0.05가 5%에 해당합니다. 계수를 추정하지 않는 조건에서는 계수 오차가 비어 있습니다. 원본 파일명은 `V4_Results_5921593e.zip`입니다.

### 관측 노이즈 10%에서의 순방향·역문제 비교

열전도와 버거스에 대해 순방향·역문제 각각 6개 방법을 시드 3234로 실행해 계획된 24개 실험을 완료했습니다. 합성 학습 관측값에 물리장 기준 크기의 10%를 표준편차로 하는 가우시안 노이즈를 더했습니다. 검증과 최종 평가는 깨끗한 참조값을 사용합니다. 무노이즈 실행과 방정식·방향·방법·시드·최적화 단계를 맞춘 48쌍에서 노이즈 비율을 제외한 실험 설정과 고정 배열 해시가 일치했습니다.

아래 화살표는 **무노이즈 → 노이즈 10%**입니다. 달성 수는 최종 고정 평가점에서 물리장 상대 L1과 L2가 모두 5% 이하인 방법 수입니다. 중앙값은 각 조건의 여섯 방법에 대한 값입니다.

| 방정식·방향 | Adam 달성 수 / 6 | L-BFGS 달성 수 / 6 | Adam 물리장 L2 중앙값 (%) | L-BFGS 물리장 L2 중앙값 (%) |
|---|---:|---:|---:|---:|
| 열전도 순방향 | 6 → 1 | 6 → 1 | 1.31 → 53.59 | 0.47 → 50.46 |
| 열전도 역문제 | 5 → 1 | 5 → 1 | 2.69 → 45.35 | 2.33 → 40.58 |
| 버거스 순방향 | 6 → 3 | 6 → 3 | 1.61 → 4.77 | 0.28 → 5.16 |
| 버거스 역문제 | 6 → 3 | 6 → 2 | 1.55 → 4.96 | 0.51 → 5.46 |

역문제의 계수 평가는 계수를 추정하는 PINN 5개 방법으로 집계했습니다. 노이즈 10%에서 열전도 손실항 SA의 L-BFGS 물리장 L2는 **3.24%**, 열확산계수 오차는 **2.31%**였습니다. 버거스 기본 PINN의 물리장 L2는 **2.20%**였지만 점성계수 오차는 **43.28%**였습니다.

| 역문제 계수 | Adam 오차 ≤5% / 5 | L-BFGS 오차 ≤5% / 5 | Adam 오차 중앙값 (%) | L-BFGS 오차 중앙값 (%) |
|---|---:|---:|---:|---:|
| 열전도 열확산계수 | 2 → 2 | 2 → 2 | 35.07 → 99.87 | 30.12 → 99.86 |
| 버거스 점성계수 | 1 → 1 | 3 → 0 | 32.17 → 71.92 | 1.30 → 43.28 |

[10% 노이즈 원본 CSV](comparison_3d5e20a6.csv) · [0%·10% 대응 비교 CSV](noise10_paired_3234.csv) · [무노이즈 원본 CSV](comparison_5921593e.csv). 대응 비교 파일의 `_pct`는 백분율, `_delta_pp`는 10% 조건에서 0% 조건을 뺀 퍼센트포인트 차이입니다. 원본 실행 파일은 `V4_Results_3d5e20a6.zip`입니다.

### 저장 모델의 시간 외삽

[시간 외삽 결과 CSV](future_to_3_3234.csv)는 시간 범위 [0, 1]에서 학습을 마친 순방향 모델 36개(6개 방정식, 6개 방법, 시드 3234)의 Adam 및 L-BFGS 가중치를 평가한 결과입니다. 원본은 `V4_Results_a4248875.zip`과 `V4_Results_5921593e.zip`입니다. 모델을 재학습하지 않고 기존 고정 평가점에서 저장 지표를 재현한 뒤, 같은 입력 정규화로 1.01부터 3.00까지 200개 시점의 예측을 합성 참조해와 비교했습니다.

공간 격자는 버거스에서 셀 중심 256개, 2차원 문제에서 32×32개입니다. CSV 오차 열은 백분율이며, 다중 출력에서는 성분별 상대 오차의 최댓값을 사용합니다. `future_*`는 전체 평가점을 모아 계산한 값이고, `endpoint_*`는 3.00 한 시점의 값입니다. 0.20 단위 열에서 예측 구간별 차이를 비교할 수 있습니다.

전체 구간에서 상대 L1과 L2가 모두 5% 이하인 모델은 Adam과 L-BFGS 각각 5/36개(버거스 3개, Taylor–Green 2개)였습니다. 3.00 한 시점에서는 두 단계 각각 버거스 3개만 충족했습니다. 버거스의 전이 중심은 `x = 0.5t`를 따라 이동해 2.00에서 공간 영역의 오른쪽 경계에 도달하므로, 이후 구간의 오차는 전이층이 영역 안에 있는 초기 구간과 함께 해석해야 합니다.

#### 초기·중기·후기 평가

각 셀은 해당 구간의 모든 평가점으로 계산한 상대 L1·L2가 모두 5% 이하인 방법 수입니다. 셀 안의 순서는 **Adam / L-BFGS**이며 방정식마다 6개 방법을 평가했습니다. CSV의 `early_*`, `middle_*`, `late_*` 열에서 개별 오차를 확인할 수 있습니다.

| 방정식 | 초기 1.01~1.20 (20시점) | 중기 1.21~2.00 (80시점) | 후기 2.01~3.00 (100시점) |

| 버거스 | 5 / 5 | 2 / 2 | 3 / 3 |
| 2차원 열전도 | 1 / 2 | 0 / 0 | 0 / 0 |
| 2차원 파동 | 0 / 0 | 0 / 0 | 0 / 0 |
| Taylor–Green | 3 / 3 | 2 / 2 | 0 / 0 |
| 반응–확산 | 3 / 3 | 2 / 1 | 0 / 0 |
| 이류–확산 | 3 / 3 | 2 / 1 | 0 / 0 |
| 합계 (각 단계 36개) | **15 / 16** | **8 / 6** | **3 / 3** |
