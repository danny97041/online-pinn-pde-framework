# V3 — 통합 결과·Colab 실행 노트북

9개 방정식의 65개 저장 실험을 비교하고, 좌표 예측·자연어 질문·선택적 추가 학습을 제공합니다.

## 일반 실행에 필요한 두 파일

1. `Online_PINN_PDE_Framework_V3.ipynb`
2. `V3_Results.zip`

두 파일을 `MyDrive/PINN`에 두고 Colab에서 노트북을 모두 실행하세요.
기본 기능은 저장 결과 조회이며 GPU·재학습·언어 모델 다운로드 없이 비교표를 볼 수 있습니다.
설정은 한국어 드롭다운으로, 결과는 맨 아래 실행 패널에 표시됩니다.

## 함께 제공하는 개발 자료

- `V3_Source.zip`: 같은 평문 소스와 개발 도구·문서.
- `V3_Release_Checksums.json`: 배포 파일의 SHA-256.

## 확인 기록

- 자연어 30 + 별도 표현 15문항, 내부 API: 통과.
- 65개 저장 모델·참조 오차, 새 학습·재개·Wave·LHS 경계: 통과.
- 비교 문구·설정 패널: 로컬 검사 통과.
- 두 Colab 검사 결과와 실행 당시 소스의 해시: 결과 ZIP에 병합.

자동 검사는 코드와 기능 동작을 대상으로 하며 브라우저 화면·계정별 공유 권한을 포함하지 않습니다.
세부 설정과 검사 범위는 저장소의 V3 사용 안내와 검증 안내에서 확인할 수 있습니다.

- 저장 수치 기반 기술보고서·기능 목록 생성, 검색 근거 편입 및 재색인.
- 방법 비교·시드 분산·방정식 히트맵, 해석해/예측/오차 지도, 저장 학습 이력의 PNG·PDF.
- 기본 1시드 유지, 선택형 4시드(3234~3237)·5개 방법 일괄 실행.
- API 스키마·라우터·서비스·모델 등록 분리와 모델 정보·배치 예측·검색 문맥 조회.
- 승인된 추론 모델 선택과 이전 선택 복원. 등록 API 쓰기는 기본 비활성.

전체 방정식 계열의 역문제와 추가 수송·음향·탄성 문제는 `V4_RESEARCH_PLAN.md`에 구현 계획으로 구분합니다.

## 모델 정보·검색 안내

- Kovasznay·Taylor–Green을 Navier–Stokes 문제로 명시합니다.
- 모델 정보는 입력·출력 기호, 의미, 영역 및 고정·추정 계수의 표로 표시합니다.
- 기본 모델 지정·복원은 자동 선택 예측 API의 기본값 변경이며 직접 선택 예측·학습 모델 변경과 구분합니다.
- 시간 선택은 x/y/t 해석해·예측·오차 지도에서만 표시합니다.
- FAISS 선택 시 실제 사용 가능 여부를 확인합니다. 미설치·로드 실패 상태에서만 설정 아래 설치 버튼을 표시합니다. 직접 클릭한 경우에만 faiss-cpu를 설치하며 의존성 패키지는 변경하지 않습니다. 설치 완료 후 로드를 확인하고 버튼을 숨깁니다. 자동 설치·검색 엔진 전환은 하지 않습니다.
- 자연어 답변과 별도로 Qwen 실제 호출 여부를 실행 로그에 표시합니다.

## 배포 구성
