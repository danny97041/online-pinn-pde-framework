# V3 개발자 배포 검증 체크리스트

배포 브랜치에서 검증한 후 승인된 커밋만 main으로 승격합니다. V1·V2와 저장 모델은 보존합니다.
과거 검사 기록을 수정본의 실행 통과로 간주하지 않습니다.

## 파일과 한 번의 검사

`Online_PINN_PDE_Framework_V3.ipynb`와 `V3_Results.zip`을 MyDrive/PINN에 둡니다.
모두 실행하면 학습 없이 결과 탭에 9개 방정식·65개 실험이 표시되어야 합니다.

설정 탭에서 아래를 선택하고 ‘선택한 기능 실행’을 한 번 누릅니다.

| 항목 | 값 |
| --- | --- |
| 사용할 기능 | 기능 검사 |
| 통합 결과 ZIP | V3_Results.zip |
| Qwen 사용 | 끔 (이후 실제 Qwen 회귀검사는 별도 실행 가능) |
| E5 + BM25 검색 | 끔 |
| 저장 모델 전수 검사 | 켬 |
| 재개·LHS 경계 검사 | 켬 |

출력 V3_Check.zip 안의 validation/runs/*.json에서 범위별 passed와 소스 해시를 확인합니다.
검사 실패도 ZIP에 남기며 다른 검사는 계속합니다. 실패·미실행 항목을 감추지 않습니다.

## 범위와 제한

- 자연어 30+15, API 및 자연어 HTTP 경로.
- 저장 선택 모델의 전수 예측, 반복·단일/배치 일치, 고정 참조 L2 재계산.
- 후보 두 방정식 새 학습 2회·재개 1회씩 (6회 + 별도 연결 검사).
- 저장된 Wave baseline Adam/계수 optimizer/SA 상태에서 동일 다음 업데이트 비교 (두 복사본, 총 2회).
- 실제 4999/5000/5001 샘플러·주기 제어, 모든 학습점 교체와 고정 평가점 해시 유지.
- 5001회 전체 학습이나 실제 세션 종료 시험을 했다고 주장하지 않습니다.
- 준비/완료 경계 ZIP을 복원하며 미완료 실험 재개는 보장하지 않습니다.
- 실행 환경·코드 해시·전체 소요시간을 기록합니다. TF 버전 일치는 요구하지 않습니다.
- Wave 재개는 저장 Adam·정규화·FF·오차를 확인하며 과거 난수 초기값의 비트 일치를 요구하지 않습니다. 새 학습의 초기 정규화 검사는 유지합니다.

한국어 조건부 위젯, 숨겨진 입력 제외, 설정→결과 이동은 실제 Colab에서도 확인합니다.
로컬 위젯 상태 테스트만으로 Colab 프런트엔드 표시까지 확인했다고 주장하지 않습니다.

## 유지관리

```bash
python tools/review_v3_source.py --baseline-zip 이전통합결과.zip
python tools/sync_v3_notebook.py
python tools/test_v3_interface.py --bundle V3_Results.zip
python tools/package_v3.py --evidence-zip 이전검사결과.zip
```

숫자 집계·학습 수식·RAG·도구 계획 소스를 비교하고 ZIP CRC/SHA와 원래 모델 파일 보존을 검사합니다.
전체 ZIP은 별도 배포 자산이며 Git에 모델 캐시나 비밀정보를 올리지 않습니다.
경계·초기조건·국소 고정밀 인증은 V3 배포 검증과 별개입니다.
