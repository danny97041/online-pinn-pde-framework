# V3 Colab 검증 절차

목적: 화면 전환, 사용자 자연어 질문, 저장 모델·재개·표본 교체 및 공유 권한을 구분하여 확인한다.
전체 실험을 재학습하지 않고 기능별로 독립적인 시험을 수행한다.
자연어·API·모델·재개 검사는 자동 시험으로, 화면·공유 권한은 브라우저 시험으로 구분한다.

## A. 최초 선택과 화면 — 모델 다운로드 없음

1. `Online_PINN_PDE_Framework_V3.ipynb`와 `V3_Results.zip`을 배치하고 모두 실행한다.
2. 선택을 변경하지 않고 60초 이상 기다린다. 셀이 약 1초 만에 끝나는 것은 정상이다.
3. 하단 대기 문구가 설정 패널로 교체되는지 확인한다. ZIP이 있으면 조회 결과, 없으면 파일 위치 안내가 표시되어야 한다.
4. 남은 초가 멈추거나 연결 실패 안내가 나오면 하단 ‘기본 조회로 바로 진행’으로 진행한다. 이는 자동 타이머 시험 통과가 아니다.
   자동 위치에서 연결된 Drive와 로컬 ZIP이 모두 없으면 Drive 인증을 한 번 요청해야 한다. 인증 취소·실패에도 패널이 남고 자동 재시도가 없어야 한다. 명시적 로컬 선택 또는 로컬 ZIP 발견 시에는 인증을 요청하지 않는다.
5. 하단에서 포아송의 기본 PINN / SA / FF / SA+FF를 바꿔 전용 설정 표시를 확인한다.
6. ‘추가 학습’에서 학습 실행 허용을 끄고 실행한다. 설정만 출력되고 optimizer 업데이트가 없어야 한다.

## B. 직접 질문과 추가 문항 — Qwen·E5 선택

‘자연어 질문’의 ‘직접 입력할 질문’에 자유롭게 작성하고 실행한다. 수치는 저장 결과·계산 도구에서 가져오고, 근거가 없는 요청은 추가 확인이나 자료 부족으로 답해야 한다.

예시:

- Poisson에서 방법별 물리장 오차를 비교해줘
- Wave에서 계수 오차가 가장 낮은 방법을 알려줘
- poisson2d baseline seed 3234 좌표 [[0.25,0.65]] 예측해줘
- Poisson 학습률 0.002로 설정 초안만 작성해줘
- 이 표에서 방법별 차이를 어떻게 읽으면 돼?

기능 검사에서 Qwen·E5를 켜고 ‘추가 시험 질문’에 위 문항을 한 줄씩 넣는다. 전수 모델·재개 검사는 끈다.
기본 30 + 별도 표현 15 + 추가 문항이 같은 ZIP에 기록된다. 추가 문항의 자동 통과는 응답 형식·허용 도구·학습 미실행 확인이며 의미 정확도는 별도 수동 확인이다.
Qwen 자체 판단과 제어기 보정은 구분한다. 자연어 답변은 수치 근거를 유지한 한국어 문장이고, 무제한 잡담·임의 코드 실행 기능은 아니다.

## C. 모델·재개 검사

Qwen·E5를 끄고 ‘저장 모델 전수 검사’, ‘재개·LHS 경계 검사’를 켠다. 추가 질문은 비운다.
학습·복원 코드 변경에 대한 회귀 시험으로 아래 항목을 확인한다.

- 65개 저장 선택 모델의 예측·고정 참조 오차 재계산
- 후보 방정식의 짧은 새 학습·재개 시험
- Wave의 저장 Adam 상태에서 두 복사본의 다음 업데이트 비교
- 4999/5000/5001 경계의 실제 LHS 교체와 평가점 유지

폐기용 모델에서 소수 업데이트를 수행하며 원본 완료 모델은 변경하지 않는다. 5001회 전체 학습이나 전체 재학습은 아니다.
생성된 `V3_Check.zip` 또는 `V3_Check_<식별자>.zip`을 보존한다. 실패·미실시는 통과로 표시하지 않는다.

## D. 공유 권한 — 별도 계정으로 수동 확인

공개 배포는 노트북·결과 ZIP에 ‘뷰어’를 사용하고 복사·다운로드를 허용한다. 공동 개발 편집자에게만 편집 권한을 준다.

1. 원본을 수정하지 않는 별도 시험용 노트북 복사본을 만든다.
2. 편집자 계정은 시험용 Markdown 문장을 변경하고 저장할 수 있는지 확인한다. 실제 파일 삭제 명령·비밀 조회는 시험하지 않는다.
3. 뷰어 계정은 원본에 변경을 저장하지 못하는지 확인한다.
4. 뷰어 계정에서 ‘Drive에 사본 저장’ 후 자기 런타임으로 실행하고, 결과 ZIP도 자기 파일 위치에서 사용한다.
5. 원본 뷰어 화면에서 직접 실행이 허용되는지는 별도로 기록한다. 허용 여부가 불명확하면 사본 실행 경로를 사용한다.

코드 접기·질문 경로의 제한은 편집 권한을 제한하는 보안 경계가 아니다. 노트북 공유로 소유자의 런타임이 공유되지는 않지만, 노트북에는 코드·텍스트·저장 출력이 포함된다.
Drive를 연결한 사용자가 수정된 코드를 실행하면 그 계정에 허용된 파일에 영향을 줄 수 있다. 소유자는 공개 편집 링크를 만들지 않고 다른 사람이 수정한 노트북을 실행하기 전에 검토한다.

공식 근거: [Colab FAQ](https://research.google.com/colaboratory/faq.html), [Drive 공유 권한](https://support.google.com/drive/answer/2494822?hl=en), [공유 제한 설정](https://support.google.com/drive/answer/2494893?hl=en).
공유 권한 시험은 자동 검사와 분리하며, 해당 시험에 사용한 계정·권한·환경을 기록한다.

## G. 서비스 확장 확인

다음 확인은 저장 모델과 결과를 사용하며 전체 benchmark 재학습을 요구하지 않습니다.

1. **보고서·기능 목록 생성**: 기술보고서 표시와 `V3_Documents.zip` 저장을 확인합니다.
2. **결과 시각화 → 방법 비교·방정식 히트맵**: 비교 그림과 `V3_Plots.zip`을 확인합니다. TensorFlow는 필요하지 않습니다.
3. **결과 시각화 → 해석해·예측·오차 지도**: 방정식·방법·시드를 선택합니다. 파동·열전도·Taylor–Green·반응–확산의 x/y/t 지도에서만 시간 위치가 표시됩니다. 방법 비교·학습 이력에는 시간 슬라이더가 없습니다. 버거스는 x–t 전체 지도를 표시합니다.
4. **추론 모델 관리 → 모델 정보 조회**: 좌표·성분·체크포인트 표시를 확인합니다. 선택 변경 승인은 기본 꺼짐이어야 합니다.
5. 선택 변경은 `/predict/active` API의 기본 모델을 저장하는 기능입니다. 직접 방법·시드를 선택하는 좌표 예측에는 영향을 주지 않습니다. **기본 추론 모델 지정 → 선택 변경 승인** 후 생성된 `V3_Registry.zip`을 입력으로 선택합니다. 기본 PINN 지정 → 푸리에 특징 지정 → **직전 기본 모델로 복원**을 실행하면 기본 PINN으로 돌아갑니다. 각 단계마다 직전에 생성된 ZIP을 입력으로 사용합니다.
6. **자연어 질문 → E5 + BM25 검색 → FAISS**를 선택합니다. FAISS가 없거나 사용할 수 없으면 설정 아래 **FAISS 설치** 버튼이 표시되고 기능 실행은 비활성화됩니다. 버튼을 눌러 설치 완료를 확인한 뒤 **선택한 기능 실행**을 누릅니다. 설치 실패·로드 실패는 통과로 기록하지 않습니다.
7. **추가 학습 → 4시드 → 학습 실행 허용 꺼짐**: 3234~3237 및 예정 실험 수만 표시되고 학습이 시작되지 않는지 확인합니다. 5개 방법 선택 시 예정 실험은 20개입니다.

새 화면·실제 E5/FAISS 경로 확인과 로컬 API·시험용 임베딩 검사는 구분합니다.

FAISS 선택만으로 설치하지 않습니다. **FAISS 설치** 버튼을 직접 눌렀을 때 고정된 `faiss-cpu` 패키지만 설치하며, 의존성 자동 설치·NumPy/TensorFlow 업그레이드는 하지 않습니다. 설치 후 실제 FAISS 로드를 다시 검사합니다. 성공하면 설치 버튼이 사라집니다. 설치 실패 시 재시도하거나 NumPy 검색으로 변경할 수 있습니다. 버튼 설치가 어려운 환경에서는 별도 코드 셀의 `%pip install -q faiss-cpu`가 대체 경로입니다.
Qwen은 의도 분류를 조언하고 최종 수치 답변은 공통 제어기가 생성하므로 Qwen 켜짐·꺼짐에서 답변이 같을 수 있습니다. 호출 여부는 실행 로그와 검사 ZIP에서 확인합니다.
